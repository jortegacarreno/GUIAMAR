# GUIAMAR web

Primera versión funcional de la web pública de GUIAMAR.

## Archivos
- `index.html`: portada
- `style.css`: estilos
- `aviso-legal.html`: aviso legal y condiciones de uso
- `assets/`: icono GUIAMAR, logo del Hospital y QR

## Publicación
Subir todos los archivos y la carpeta `assets` a la raíz del repositorio GitHub `GUIAMAR`, rama `principal`.
GitHub Pages los publicará automáticamente.
