Política de privacidad

GUIAMAR es una aplicación del Hospital Universitario Torrecárdenas, dirigida a profesionales sanitarios y orientada a facilitar la consulta de información farmacológica relacionada con medicamentos de alto riesgo.

El referente funcional de la aplicación es el Servicio de Farmacia Hospitalaria del Hospital Universitario Torrecárdenas.

1. Datos personales

GUIAMAR no requiere registro de usuario, creación de cuenta ni autenticación para su uso.

La aplicación no recopila, almacena ni transmite datos personales de pacientes ni información clínica identificable.

2. Favoritos

La aplicación permite marcar principios activos como favoritos. Esta información se almacena exclusivamente de forma local en el dispositivo del usuario y no se envía a servidores externos.

3. Base de datos farmacológica

GUIAMAR incorpora una base de datos farmacológica local para permitir el funcionamiento de la aplicación incluso sin conexión a Internet.

La aplicación puede consultar periódicamente una versión remota de esta base de datos para comprobar si existe una actualización disponible. Cuando procede, la nueva base de datos se descarga desde la infraestructura web asociada a GUIAMAR.

Este proceso de actualización no requiere el envío de datos personales del usuario.

4. Fichas técnicas y contenidos externos

GUIAMAR puede facilitar el acceso a fichas técnicas oficiales de medicamentos y otros recursos externos relacionados con la información farmacológica mostrada en la aplicación.

Cuando se accede a un recurso externo, pueden aplicarse las condiciones de uso y políticas de privacidad del sitio o servicio correspondiente.

5. Comunicación de incidencias o sugerencias sobre medicamentos

GUIAMAR permite iniciar una comunicación por correo electrónico para informar de incidencias o realizar sugerencias relacionadas con un medicamento concreto.

La aplicación no envía correos directamente ni almacena el contenido de estos mensajes. La comunicación se realiza mediante la aplicación de correo configurada en el dispositivo del usuario.

Cualquier dato personal que el usuario decida incluir voluntariamente en dicho correo será tratado conforme a las condiciones del servicio de correo utilizado y a la normativa aplicable.

6. Permisos del dispositivo

GUIAMAR no solicita acceso a contactos, ubicación, cámara, micrófono, llamadas telefónicas ni otros datos sensibles del dispositivo para su funcionamiento habitual.

7. Servicios de terceros

La aplicación utiliza servicios externos exclusivamente para funciones técnicas necesarias, como la consulta y descarga de actualizaciones de la base de datos o el acceso a documentación farmacológica.

GUIAMAR no utiliza servicios publicitarios ni realiza seguimiento del usuario con fines comerciales.

8. Finalidad de la aplicación

GUIAMAR está destinada exclusivamente a profesionales sanitarios y tiene carácter informativo y de apoyo a la práctica clínica.

GUIAMAR no es un dispositivo médico y no está destinada a diagnosticar, tratar, curar ni prevenir enfermedades.

La información proporcionada no sustituye la ficha técnica oficial del medicamento, los protocolos y procedimientos vigentes, las recomendaciones de las autoridades sanitarias ni el juicio clínico del profesional responsable.

9. Cambios en esta política

Esta política de privacidad podrá actualizarse cuando se produzcan cambios relevantes en el funcionamiento de la aplicación o en la normativa aplicable.

10. Información institucional y contacto

GUIAMAR es una aplicación del Hospital Universitario Torrecárdenas, cuyo referente funcional es el Servicio de Farmacia Hospitalaria.

Para cuestiones relacionadas con el contenido farmacológico de la aplicación, incidencias o sugerencias, los usuarios pueden dirigirse al Servicio de Farmacia del Hospital Universitario Torrecárdenas.

Además, desde la ficha de cada medicamento puede iniciarse una comunicación por correo electrónico para informar de incidencias o realizar sugerencias relacionadas con dicho medicamento.

Última actualización: septiembre de 2026.
